## 0. 方法与口径

- **成员池**：权重已在 Release 发布（fp16）且 **train-only**（可用 valid 调参）的成员：cb512、hi512_v2、seed2、cb384、b448、b384、b512、ctiny384（8 个）。swin pair / swinl / 22k / pw3 / hi640 / RA 概率线权重未发布 → 不可部署，排除（MEMBERS.md §3）。
- **目标**：valid（5849，阳性 191，3.27%）**AUPRC 最大化**；概率空间线性加权（`predict.py --blend` 可直接部署）。
- **搜索**：前向贪心 + 每步坐标下降网格精调（粗 0.05 / 细 0.01），k≤3 穷举交叉核对。
- **体积约束**：解压后实际加载权重合计 ≤ 500,000,000 B，硬淘汰。
- **概率口径（重要）**：成员概率来自本地 ens8 缓存（2026-10-17）。ConvNeXt 三成员（cb512/hi512_v2/cb384）为**多尺度 TTA**（3 尺度×4 翻转），effnet/seed2 为单尺度 TTA4；各成员官方 TTA4 单尺度值见 MEMBERS.md §1 两列对照。**候选终值需 GPU 统一 TTA4 口径复核**（已列入待办，与 T4 实测同批）。
- **复现命令**（脚本按 regime 过滤，禁止混合口径出融合值）：

  ```bash
  # 本文档数值口径（ens8 本地缓存概率，混合 TTA regime）
  python tools/finals_208_search.py --ens8-dir D:/glaucoma_work/ens8_probs \
      --assets-dir D:/glaucoma_work/finals_208_assets --regime legacy \
      --out docs/finals/candidates_208_search.json
  # 统一 TTA4 口径（PIL 直推复算 npz，probs_tta4）——定稿用，结果回填 §4
  python tools/finals_208_search.py --pil-dir .scratch_208 --regime pil4 \
      --out docs/finals/candidates_208_search_pil4.json
  ```
- test 概率未参与任何搜索（规则第 5 条）。

## 4. TTA 档位与延迟（供 #207 交叉）

- 候选表所列 valid AUPRC 为 ens8 多尺度口径；**统一 TTA4 单尺度口径的保守预期：−0.001~−0.003**（按 ConvNeXt 成员权重占比 × 其单尺度损失 −0.0026~−0.0028 估算）；**TTA1 再 −0.000~−0.001**（翻转平均效应小）。
- 三候选的部署起点都是 **TTA1**：以 5060 batch=1 ~39ms/前向单位折算，C2≈117ms、C3≈154ms、C1≈167ms、C0≈117ms（C0 为实测值）——**全部超过 100ms**，T4 上必须依靠 #207 的预处理/前向流水重叠、fp16、预热等手段压到 ≤85ms 目标；若压不进，**降级路径 = C2 − b512（cb512+hi512_v2 两成员 2.77 单位，valid AUPRC 0.88260）**。
- T4 实测矩阵（每成员 × 精度 × TTA + 每候选组合）由工程工单 #207 产出 `docs/finals/T4_LATENCY.md` 后回填本表。
